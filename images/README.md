В этой папке хранятся изображения карточек, фавиконки и значок для iOS.

## Иллюстрации карточек

Первая картинка (`bus.webp`, `bus.jpg`, `bus.png`) предоставлена вместе с макетом проекта.

Остальные иллюстрации — работы [kaijupxl на GIPHY](https://giphy.com/kaijupxl).
В описании профиля автор разрешает некоммерческое использование с указанием авторства.
Для этого учебного проекта взяты первые статичные кадры оригинальных GIF.
Рисунки сохранены в PNG и WebP без потери качества; анимации не включены.
